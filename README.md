# Hai tiếng, một tuổi thơ

Web tĩnh bằng HTML, CSS và JavaScript giúp gia đình Việt Nam chọn hoạt động song ngữ Việt–Anh phù hợp với bé từ sơ sinh đến khoảng 6 tuổi.

## Xem web

Sau khi GitHub Pages được bật, trang được xuất bản tại <https://khangtu22.github.io/baby/>.

## Chạy trên máy

Mở `index.html` trong trình duyệt hoặc chạy một máy chủ tĩnh trong thư mục này, ví dụ:

```sh
python3 -m http.server 8000
```

Sau đó mở <http://localhost:8000/>.

Ngày sinh và dấu “đã thử” chỉ được lưu trong `localStorage` trên thiết bị đang dùng. Web không gửi dữ liệu này lên máy chủ.

Nội dung hoạt động là gợi ý tương tác cho người chăm sóc, không phải công cụ đánh giá hay chẩn đoán phát triển.
